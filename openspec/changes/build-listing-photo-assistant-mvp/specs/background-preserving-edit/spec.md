## Purpose

撮影した衣類の柄・色・形・傷・汚れ・使用感を保ったまま背景だけを整え、利用者が編集結果を比較してから出品用画像を選べるようにする。

## ADDED Requirements

### Requirement: 撮影完了後に元画像を保持した編集を開始できる

システム SHALL、必須写真が揃った撮影セッションから編集を開始できるようにし、背景編集の開始時点で少なくとも1枚の元画像を変更せずに保持する。編集処理中も利用者が元画像を確認できなければならない。

#### Scenario: 必須写真の撮影から編集へ進む

- **WHEN** 正面、背面、タグの必須写真が受け入れられ、利用者が編集開始を選択する
- **THEN** システムは元画像を保持したまま、背景の選択とマスク処理の状態を表示する

#### Scenario: 撮影が未完了の状態で編集を開こうとする

- **WHEN** 必須写真のいずれかが未取得または品質不良である
- **THEN** システムは編集完了として扱わず、不足している撮影へ戻る操作を提示する

### Requirement: 商品領域は元画像に基づいて合成する

システム SHALL、商品マスクを用いて元画像の商品領域と選択した背景を合成し、商品領域の画素情報を生成 AI による描き直し、着用画像化、色・形状変更、傷・汚れの除去などで改変してはならない。マスクが商品を正しく覆っているか利用者が確認できる状態を提供する。

#### Scenario: 背景だけを変更したプレビューを生成する

- **WHEN** 利用者が利用可能な背景を選択し、商品マスクの生成が成功する
- **THEN** システムは元画像の商品を前景として保持し、選択背景と合成したプレビューを表示する

#### Scenario: 商品マスクの生成に失敗する

- **WHEN** マスク処理がタイムアウト、エラー、または利用できないマスク結果を返す
- **THEN** システムは編集済み画像を承認済みとして表示せず、元画像の確認またはマスク処理の再試行を提示する

### Requirement: 利用者が背景を選択できる

システム SHALL、利用者が複数の利用可能な背景から1つを選択し、選択中の背景を識別できるようにする。背景の選択を変更した場合は、同じ元画像と商品マスクを使った比較可能なプレビューを生成する。

#### Scenario: 背景を切り替える

- **WHEN** 利用者が別の背景候補を選択する
- **THEN** システムは選択状態を更新し、商品自体を変更せずに新しい背景との合成プレビューを表示する

### Requirement: 編集前後を比較してから承認する

システム SHALL、元画像と編集後画像を同じ商品について比較できる UI を提供し、編集後画像を初期状態で承認済みにしてはならない。利用者が編集後画像を採用する、または元画像を使う操作を明示的に選択した場合のみ、出品用画像を確定する。

#### Scenario: 編集結果を採用する

- **WHEN** 利用者が元画像と編集後画像を比較し、「この背景を使う」に相当する採用操作を選択する
- **THEN** システムは選択中の編集後画像を承認済みの出品用画像として確定し、元画像も別途確認できる状態で保持する

#### Scenario: 元画像を使う

- **WHEN** 利用者が比較後に元画像を使う操作を選択する
- **THEN** システムは編集結果を採用せず、元画像を出品用画像として確定する

#### Scenario: 比較中に編集を取り消す

- **WHEN** 利用者が承認前に編集を取り消す、または別の背景へ切り替える
- **THEN** システムは承認状態を確定せず、元画像または新しい背景のプレビューを表示する

### Requirement: 編集処理の失敗から安全に復帰できる

システム SHALL、画像の読み込み失敗、マスク生成失敗、合成処理のタイムアウトを利用者に明示し、元画像を失わずに再試行または編集を中止できるようにする。処理失敗時に不完全な編集画像を出品用画像として確定してはならない。

#### Scenario: 編集サービスが一時的に利用できない

- **WHEN** 背景分離または合成処理が一時的なエラーを返す
- **THEN** システムは元画像を表示可能な状態で保持し、再試行と元画像採用の選択肢を提示する

### Requirement: 承認した画像を出力できる

システム SHALL、利用者が確定した出品用画像を端末へ保存または次の出品操作へ渡せる出力として提供し、元画像と編集後画像のどちらを確定したかを利用者が識別できるようにする。

#### Scenario: 編集後画像を確定して出力する

- **WHEN** 利用者が編集後画像を承認し、出力操作を選択する
- **THEN** システムは承認済みの編集後画像を出力し、未承認のプレビューだけを出力することはない
