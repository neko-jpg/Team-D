# Mercari AI Agent Hackathon — 出品撮影伴走AI Agent

服を売りたいのに、撮影環境や撮影・採寸の知識がなく出品を諦めてしまう人に対して、出品に必要な写真が揃うまで伴走するAI Agentの企画である。

## 概要

本企画は「Mercari AI Agent Hackathon for PM」に向けたTeam-Dのプロジェクトである。

完成した写真を採点するだけではなく、ユーザーが衣類を撮影するたびにAI Agentが内容と品質を確認し、次に必要な写真や撮り直し方を案内する。必要な写真が揃った後は、実物の商品情報を保ったまま背景を整え、出品に使える画像一式を完成させる。

現在、このリポジトリには企画・要件・技術設計・OSS調査のMarkdown資料を収録している。

## 解決する課題

対象は、売りたい服と出品する意思はあるものの、商品写真をうまく用意できず出品前に止まってしまう人である。

- 生活感のある背景が写り込む
- 商品がきれいに映る撮影場所がない
- どの角度から撮ればよいか分からない
- 必要な写真の種類や枚数が分からない
- 身幅や肩幅などの測り方が分からない
- 撮影した写真に自信を持てない

商品や出品意思がないのではなく、商品を市場に出すための撮影環境・撮影知識・採寸知識が不足していることを解決する。

## 提案する体験

```text
売りたい服を撮影する
  ↓
AI Agentが写真の内容と品質を確認する
  ↓
不足している写真、または撮り直し方を案内する
  ↓
ユーザーが追加撮影する
  ↓
必要な写真が揃うまで確認と案内を繰り返す
  ↓
実物の商品を残したまま背景を整える
  ↓
元画像と編集後画像を比較し、ユーザーが承認する
  ↓
出品用画像が完成する
```

## AI Agentが担うこと

- 写っている衣類を認識する
- 正面・背面・タグなど、写真の種類を判断する
- ブレ・暗さ・不鮮明さなどを確認する
- 不足している写真を判断する
- 次に撮影する角度や構図を具体的に案内する
- 問題の理由と撮り直し方を伝える
- 必要な写真が揃うまで撮影を伴走する
- 完成した画像を出品用に整理する

AIに画面遷移を自由に決めさせるのではなく、判定結果を限定された形式で返し、アプリ側が安全に状態を管理する設計とする。

## 商品画像を扱う原則

中古品では、魅力的に見せることと実物を正確に伝えることの両立が必要である。

- 撮影した現物の商品写真を使用する
- 商品自体を生成AIで描き直さない
- 商品と背景を分離し、背景だけを編集する
- 柄・色・形・傷・汚れ・使用感を保持する
- 元画像を必ず残す
- 編集前後を比較できるようにする
- 最終的な採用判断はユーザーが行う

## 実装構想

ReactとTypeScriptによるモバイルWebを想定している。スマートフォンで撮影した画像をバックエンド経由で画像AIへ送り、構造化された判定結果に基づいて撮影フローを進める。

背景処理では商品マスクを生成し、元の商品画像と選択した背景をCanvas上で合成する。採寸機能を追加する場合は、平置き衣類と基準物を撮影し、自動検出した測定点をユーザーが確認・修正する半自動方式を採用する。
